# Conditional DDPM Baseline

Source-only snapshot of the conditional DDPM comparison implementation.

| File | Purpose |
|---|---|
| `Train_condition.py` | Conditional DDPM training entry point. |
| `Test_condition.py` | Conditional DDPM test entry point. |
| `inference_3d.py` | Volume reconstruction/inference helper. |
| `Diffusion_condition.py` | Diffusion process implementation. |
| `Model_condition.py` | Conditional model architecture. |
| `datasets.py` | Training dataset loader. |
| `datasets_test.py` | Test dataset loader. |
| `UPSTREAM_README.md` | Original notes. |

Checkpoint folders, generated tests, images, caches, and Git history were
excluded.
