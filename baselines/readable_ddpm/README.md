# Readable Conditional DDPM Baseline

Source-only snapshot of the Readable Conditional Denoising Diffusion
comparison code.

- `diffusion3d/`: 3D diffusion training/inference code, configs, models, and
  utilities.
- `img2img2D/`: 2D image-to-image diffusion/CUT code and configs.
- `UPSTREAM_README.md`: upstream repository overview.

Large `.npy` data, logs, generated images, and caches were excluded. Configure
dataset and weight paths before use.
