# CycleGAN / pix2pix Baseline

Source-only snapshot of the comparison implementation.

- `train.py`: baseline training entry point.
- `test.py`: baseline test entry point.
- `models/`: CycleGAN and pix2pix model definitions.
- `data/`: dataset loader source only; embedded HN arrays were removed.
- `options/`: command-line option definitions.
- `util/`: visualization and I/O helpers.
- `scripts/`: upstream download and launch scripts.
- `UPSTREAM_README.md`: original usage documentation.

The original `checkpoints/`, `results/`, `.git/`, and embedded dataset arrays
are not included.
